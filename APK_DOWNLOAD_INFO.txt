2. SECURE KEYSTORE STORAGE & BACKUP
-------------------------------------------------------------------
- Keystore directory: android/keystores/ (ignored by git in .gitignore)
- Configuration: android/keystore.properties (ignored by git in .gitignore)
- Configuration Template: android/keystore.properties.example
- Downloadable Backup Archive: /arrow-master-keystores-backup.tar.gz

How to backup your keystore offline:
1. Download arrow-master-keystores-backup.tar.gz immediately.
2. Extract and store the `.jks` keystore files and `keystore.properties` on an encrypted, secure drive (e.g., password manager, hardware drive).
3. NEVER commit `.jks`, `.keystore`, or `keystore.properties` files to public Git repositories.
4. If you lose your Amazon release keystore, Amazon Appstore cannot recover it and you cannot update your game.
5. For Google Play, if you ever lose your upload key, you can reset it via Google Play Console support using Google Play App Signing.
